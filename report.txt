Lyrics matching
The two downloaded files have video titles with extra credits, and list the uploader as the artist. The previous release sent those tags to LRCLIB and reported no match.

The installed lookup in src-tauri/src/lyrics/mod.rs searches by a cleaned song title and checks the performer against the credits. It accepts timestamps only for a close duration match and can use plain lyrics for a different-length recording.
- Ghulam Ali, “Yeh Dil Ye Pagal Dil Mera (Awargi)” — the file is 418.536 seconds. LRCLIB returned a 419-second recording with timed lyrics. The live regression test confirmed the lookup returned synced lyrics.
- Jagjit Singh, “Kal Chaudhvin Ki Raat Thi” — the file is 391.128 seconds. One provider result is 371 seconds. The live test confirmed lyrics were found but did not assert whether they were plain or timed.

Lyrics and intro controls
The Ubuntu desktop release now offers original script and offline Latin romanization for supported South Asian scripts. Timed lines follow playback and seek on selection. For plain lyrics, automatic estimated timing distributes lines over the recording by word count after the saved intro. Previously completed manual timings are respected. Original and Romanized use inline buttons. Skip intro to here remembers a playback start for existing downloads with an unmarked ad. Reset intro skip restores the full recording.
