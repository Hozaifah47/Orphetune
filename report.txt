Lyrics matching
The two downloaded files have video titles with extra credits, and list the uploader as the artist. The previous release sent those tags to LRCLIB and reported no match.

The installed lookup in src-tauri/src/lyrics/mod.rs searches by a cleaned song title and checks the performer against the credits. It accepts timestamps only for a close duration match and can use plain lyrics for a different-length recording.
- Ghulam Ali, “Yeh Dil Ye Pagal Dil Mera (Awargi)” — the file is 418.536 seconds. LRCLIB returned a 419-second recording with timed lyrics. The live regression test confirmed the lookup returned synced lyrics.
- Jagjit Singh, “Kal Chaudhvin Ki Raat Thi” — the file is 391.128 seconds. One provider result is 371 seconds. The live test confirmed lyrics were found but did not assert whether they were plain or timed.

The frontend suite passed all 16 tests. All four Rust tests passed, including the live lyrics test. Rust formatting, strict Clippy and the release build passed. The installed executable matched the release build and started from the desktop launcher. In a local audio fixture the downloader removed a three-second marked sponsor segment from a ten-second track, producing a 7.05-second MP3.

Lyrics and intro controls
The Ubuntu desktop release now offers original script and offline Latin romanization for supported South Asian scripts. Timed lines follow playback and seek on selection. For plain lyrics, Sync lines records each line onset during playback and saves the completed timing for that song. Skip intro to here remembers a playback start for existing downloads with an unmarked ad. Reset intro skip restores the full recording.
The frontend suite and release build passed. Manual singing alignment and intro-marker playback on a saved song still need a listening check. The production dependency audit passed. The full npm audit reported three development dependency findings.
